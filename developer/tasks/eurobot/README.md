# Eurobot course tasks

This subfolder holds task docs for the Eurobot robotics course fork
(`Robotics010/strictdoc`), kept apart from the upstream-derived task history in
the parent `developer/tasks/` folder.

Each task lives under `eurobot/<date>_<slug>/task.md`, written with the same
WHY/WHAT/HOW structure as `../task.template.md` — use that file as the
skeleton for a new task. Agent working memory for a task goes in a sibling
`Context.md`, per the "Development tasks" section of the root `AGENTS.md`.
