Titles, relation types, and diagnostics

mode: levels

A long title wraps and stops after three lines. The full title is in the tooltip. B -> A has the input type verifies with its own style. C -> A has the input type unknown without a style: it gets the default style. C relates to itself, and B -> A is given twice: the generator drops both and marks the nodes with a warning sign.

Built-in relation types: warning (dashed) marks a relation across levels, danger (red) marks a cycle. The "!" sign marks a node with a diagnostic.

Extreme gate, left: L sends 12, U receives 4

mode: levels

L -> U is straight. L sends 12 relations to the left. U receives 4 relations from the left. All of them use the left group of the gate between U and L. The group is unsafe: the segments into U run right in the bottom half, the segments out of L run left in the top half. The faces share one slot list, so each port skips the slots of the other face.

Built-in relation types: warning (dashed) marks a relation across levels, danger (red) marks a cycle. The "!" sign marks a node with a diagnostic.
