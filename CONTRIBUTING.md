# Contributing

This repository is a course-internal fork of StrictDoc; it does not follow
upstream StrictDoc's own contribution process. Engineering conventions live in
`AGENTS.md` and the StrictDoc Developer Guide (`docs/strictdoc_11_developer_guide.sdoc`)
it points to. Review and merge happen inside this repository, not via pull
requests or issues filed against `strictdoc-project/strictdoc`.

For background on the upstream tool's own (unrelated) contribution process,
see [Contributing to StrictDoc](https://strictdoc.readthedocs.io/en/latest/latest/docs/strictdoc_10_contributing.html).
